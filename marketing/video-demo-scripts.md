## Link placement before publishing

For YouTube Shorts, description and comment URLs are non-clickable. Use a clickable channel profile link to the tracked freelance page and say “Free invoice tool: link on my channel.” A pinned comment should repeat that instruction rather than promise a clickable link. Use `utm_source=youtube_shorts&utm_medium=video&utm_campaign=first_invoice&utm_content=channel_profile` for that profile link. Check each other platform's actual account features before reusing the CTA.

## 🎥 Recording & Production Checklist (Days 1–3)
1. **Screen Recording Tool:** Use OBS Studio, Loom, or Mac QuickTime (CMD+Shift+5) set to 1080x1920 (9:16 portrait) or crop standard 16:9 4K window.
2. **Browser Window Settings:**
   - URL to open: `https://quickbillfree.com/?preset=freelance`
   - Browser zoom: 125%–150% so line items and rates are crisp on mobile phones.
   - Clean profile with zero bookmarks bar or personal tabs visible.
3. **Audio:** Record clear voiceover using phone mic or podcast mic with crisp background music (low volume, e.g. lofi or upbeat indie tech beat).
4. **Captions:** Generate automatic TikTok / CapCut / Premiere captions with yellow/white highlight words.
