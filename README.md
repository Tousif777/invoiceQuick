## ✨ Features

- **🔒 100% Private & Client-Side**: All invoice data, business details, line items, and uploaded logos stay strictly inside your browser's `localStorage`. No data is ever transmitted to external servers.
- **⚡ Instant PDF Generation**: Pixel-perfect vector PDF output using native browser print and client-side HTML-to-PDF rendering.
- **🎨 4 Professional Templates**: Switch between Modern, Classic, Creative, and Compact layouts in real-time.
- **💱 Multi-Currency Support**: Instant formatting for USD ($), EUR (€), GBP (£), CAD (CA$), AUD (A$), and INR (₹).
- **📱 Payment QR Codes**: Generate instant Venmo, PayPal, Stripe, and Wise payment QR codes directly onto your invoice.
- **📂 Client & Service Presets**: Save frequent clients and quick freelance services for one-click insertion.
- **📝 Multiple Document Types**: Create Standard Invoices, Tax Invoices, Proforma Invoices, Quotes/Estimates, and Receipts.

## 🚀 Quick Start (Local Run)

Simply clone this repository and open `index.html` in any web browser:

```bash
git clone https://github.com/Tousif777/invoiceQuick.git
cd invoiceQuick
open index.html
```

No Node.js backend, Docker, or build step required — built with clean Vanilla HTML5, CSS3, and modern JavaScript.
