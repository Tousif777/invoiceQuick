## 1. Platform Architecture & Tech Stack

QuickBillFree is engineered as a **100% private, client-side progressive web application (PWA)**:
* **Zero Backend Storage:** All customer records, invoices, calculations, and PDF generation happen strictly in the user's browser memory via HTML5 Canvas, LocalStorage, and `html2pdf.js` / `jsPDF`.
* **Zero Account Walls:** Users generate, print, and download PDF invoices with zero signups, zero logins, and zero credit cards.
* **PWA Offline Support:** Powered by `sw.js` and `manifest.json`, the app works completely offline when internet access drops.
* **Consent Mode v2 & AdSense:** Google Consent Mode v2 integrated with Google AdSense (`ca-pub-7599767103475954`) and Google Analytics 4 (`G-WH81YDKPS6`).
